# Reference photographs used for the photo review

On 2026-09-29 the owner allowed a photo-based review. Sixteen real photographs of Jaipur were downloaded from Wikimedia Commons (1280 px thumbnails, about 5 MB in total) into a scratch folder **outside the repository**: the images are **not committed** (size, and each keeps its own licence). This file is the credit list; every file is CC0, CC BY or CC BY-SA. The review was done by comparing them with the model's screenshots (`npm run shots`).

A search for Jaipur kite, Diwali-market and monsoon-street photographs on Commons returned nothing usable (the one kite photo found was a modern delta kite, not a patang, and was discarded), so those three scenes have **no photographic reference**.

Two things read off these photographs and used in the model (both *approx*, measured by eye, not surveyed): the tier widths of Hawa Mahal (about 100 / 100 / 97 / 75 / 41 % of the base width, from `hawa-east-2022`), and the wall hue (terracotta-orange rather than rose).
